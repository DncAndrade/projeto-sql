# Banco de Dados em SQL

Este projeto prático simula o banco de dados de uma loja virtual para responder a perguntas estratégicas de negócio.

## 📊 O que eu desenvolvi:
- **Tabelas:** Clientes e Pedidos.
- **Relacionamentos:** Uso de Chave Primária e Chave Estrangeira.
- **Consultas Avançadas:** Filtros com `WHERE`, cruzamento de dados com `INNER JOIN` e faturamento por cliente usando `GROUP BY` e `SUM`.
